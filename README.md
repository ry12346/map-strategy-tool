# 真戦 PK2マップ

「信長の野望 真戦」PK2シーズン向けの非公式マップツールです。

スマホ利用を標準として、作戦記号の編集機能を外し、地図確認・城関所検索・経路探索・資源州確認に絞っています。

## 主な機能

- PK2マップの閲覧、拡大縮小
- 城・関所検索
- 城名／関所名の表示切り替え
- 関所レベル表示
- 北側／南側の資源州エリア表示
- 陸路・海上航路を含む経路探索
- 通行不可関所を指定した迂回探索
- 別ルート候補の表示
- ゲーム座標表示・コピー

## スマホ操作

- 1本指ドラッグ：地図移動
- 2本指：拡大・縮小
- 城・関所をタップ：地点メニュー
- 右下「経路」：経路探索
- 上部「城名」「関所名」「資源州」：表示切り替え

## 注意

本ツールは非公式のファンツールであり、ゲーム運営会社とは関係ありません。
