# 真戦 戦略・俯瞰ツール

「信長の野望 真戦」で、一門の指揮官が攻略方針を作成し、あとから共有するための非公式Webツールです。

サーバー側プログラムやデータベースは使用しません。画像や作戦内容は、利用者がファイルとして保存・共有しない限り、ブラウザの外へ送信されません。

## 使い方

1. `index.html` をブラウザで開きます。
2. 「マップ画像」から、結合済みのマップ画像を選びます。
3. 左側から記号を選び、地図上へ配置します。
4. 配置した記号を選択し、右側で名称・説明・色・大きさ・作戦段階を編集します。
5. 「共有・出力」から、用途に応じたファイルを保存します。

利用できる主な記号は次のとおりです。

- 自軍、敵軍、駐屯、幕舎、陣城
- 城、関所、橋、駅路、攻略目標
- 侵攻矢印、防衛線、強調範囲、メモ
- 共通、第1段階、第2段階、第3段階、予備の表示切替

## 保存形式

### 作戦保存（`.nssmap`）

背景マップと配置内容をまとめた編集用ファイルです。別の端末でも「作戦読込」から続きを編集できます。

### 共有用HTML

背景マップと完成した作戦図を1つのHTMLファイルにまとめます。受け取った人は、ブラウザで開いて拡大・移動・作戦段階の切替ができます。編集はできません。

### PNG

Discordへの貼り付けや、画像としての保管に使用します。「全体」と「現在の表示範囲」を選べます。

## 注意

本ツールは非公式のファンツールであり、ゲーム運営会社とは関係ありません。ゲーム画面の画像や作戦情報は、一門内の運用方針に従って管理してください。
