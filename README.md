# 真戦 作戦図エディタ

「信長の野望 真戦」で、一門の指揮官が攻略方針を作成し、あとから共有するための非公式Webツールです。

サーバー側プログラムやデータベースは使用しません。画像や作戦内容は、利用者がファイルとして保存・共有しない限り、ブラウザの外へ送信されません。

## 収録ファイル

- `index.html`：作戦図エディタ
- `map-maker.html`：複数スクリーンショットの結合画面
- `test-map.png`：操作確認用の簡易マップ
- `sample-plan.nssmap`：背景と作戦記号を含む操作確認用サンプル
- `MAP_CAPTURE_GUIDE.md`：ゲームマップ撮影手順
- `MANUAL_UPLOAD.md`：手動アップロード手順

## 作戦図エディタの使い方

1. `index.html` をブラウザで開きます。
2. 「マップ画像」から、結合済みのマップ画像を選びます。
3. 左側から記号を選び、地図上へ配置します。
4. 配置した記号を選択し、右側で名称・説明・色・大きさ・作戦段階を編集します。
5. 「共有・出力」から、用途に応じたファイルを保存します。

利用できる主な記号は次のとおりです。

- 自軍、敵軍、駐屯、幕舎、陣城
- 城、関所、橋、駅路、攻略目標
- 侵攻矢印、防衛線、強調範囲、メモ
- 共通、第1段階、第2段階、第3段階、予備の表示切替

## 保存形式

### 作戦保存（`.nssmap`）

背景マップと配置内容をまとめた編集用ファイルです。別の端末でも「作戦読込」から続きを編集できます。

### 共有用HTML

背景マップと完成した作戦図を1つのHTMLファイルにまとめます。受け取った人は、ブラウザで開いて拡大・移動・作戦段階の切替ができます。編集はできません。

### PNG

Discordへの貼り付けや、画像としての保管に使用します。「全体」と「現在の表示範囲」を選べます。

## マップ画像作成

1. `map-maker.html` を開きます。
2. 同じ倍率・同じ画面サイズで撮影したスクリーンショットをまとめて追加します。
3. 横方向の枚数と重なり率を設定し、「ファイル名順に配置」を実行します。
4. 不透明度を下げ、矢印キーで重なりを微調整します。
5. 「結合PNG出力」で保存し、作戦図エディタの背景として使用します。

スクリーンショットの具体的な撮り方は `MAP_CAPTURE_GUIDE.md` を参照してください。

## ローカルでの確認

ZIPを展開し、`index.html` をダブルクリックして開けます。すぐに全機能を確認する場合は「作戦読込」から `sample-plan.nssmap` を選択してください。新規作戦を試す場合は、`test-map.png` を背景として使用できます。

## 公開

GitHub連携は不要です。フォルダ内のファイルを構成を変えずに、GitHub Pagesなどの静的Webサイトへ手動アップロードします。詳しくは `MANUAL_UPLOAD.md` を参照してください。

## 注意

本ツールは非公式のファンツールであり、ゲーム運営会社とは関係ありません。ゲーム画面の画像や作戦情報は、一門内の運用方針に従って管理してください。
