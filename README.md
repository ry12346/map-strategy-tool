# 真戦 戦略マップ

PK1シーズン用の作戦作成・経路探索ツールです。ブラウザで `index.html` を開いて使用します。

## 主な機能

- PK1標準マップの拡大・縮小・ドラッグ移動
- 自軍、敵軍、駐屯、幕舎、陣城、遷城、侵攻、防衛線、目標、メモの配置
- 配置した記号の移動・サイズ変更・色変更
- 防衛線の長さ変更・回転
- 作戦案A/B/Cの切り替え
- 作戦タイムラインの登録と段階切り替え
- 城・関所名の表示／非表示
- 城・関所の検索
- 城・関所の右クリック操作
- 関所を通行不可にした陸路経路探索
- 最短経路に加え、必要に応じて経路候補2・3を同時表示
- ゲーム座標の表示
- 作戦ファイルの保存／読込
- 現在の表示範囲のPNG・閲覧用HTMLへの出力

## 基本操作

- **地図上をドラッグ**: マップを移動
- **マウスホイール**: 拡大・縮小
- **記号上をドラッグ**: 記号を移動
- **選択した記号のハンドルをドラッグ**: サイズ変更
- **防衛線の端点**: 長さ・向きを変更
- **防衛線の回転ハンドル**: 回転
- **城・関所を右クリック**: 経路点追加、座標コピー、関所の通行可否切り替え

## 経路探索

1. 左側の「経路」を選びます。
2. マップ上で開始地点と到着地点をクリックします。必要なら経由地点も追加できます。
3. 通行不可にしたい関所があれば右側で指定します。
4. 「経路計算」を押します。
5. 別経路も確認したい場合は「経路候補2」「経路候補3」をチェックします。

経路探索は陸路のみです。

## 作戦案A/B/C

A/B/Cは別々の作戦として管理されます。配置記号、経路、通行不可関所、タイムラインは作戦案ごとに保存されます。

## 作戦タイムライン

「＋追加」で工程を追加し、時刻・工程名・作戦段階を入力します。「表示」を押すと、その工程に対応した作戦段階へ切り替わります。

## 保存と共有

- **作戦保存**: 後から再編集できる作戦ファイルを保存します。
- **作戦読込**: 保存済みの作戦ファイルを開きます。
- **共有・出力**: 現在の表示範囲のPNG画像や閲覧用HTMLを作成します。共有用HTMLには、出力時の城・関所の表示設定や作戦段階が反映されます。
