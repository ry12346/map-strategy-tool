# 真戦 戦略マップ

PK1シーズン用の作戦作成・経路探索ツールです。ブラウザで `index.html` を開いて使用します。

## 主な機能

- PK1標準マップの拡大・縮小・ドラッグ移動
- 自軍、敵軍、駐屯、幕舎、陣城、遷城、侵攻、防衛線、目標、メモの配置
- 配置した記号の移動・サイズ変更・文字サイズ変更・記号本体の表示切り替え
- 防衛線の長さ変更・回転
- 作戦案A/B/Cの切り替え
- 城・関所名の表示／非表示
- 城・関所の検索
- 地図上の右クリック／スマホ長押しによる地点操作
- 関所を通行不可にした陸路経路探索
- 最短マス数を優先し、同じ最短距離なら駅路をより多く通る経路を優先
- 必要に応じて、経路1と重ならない経路候補2・3を同時表示
- ゲーム座標の表示
- 作戦ファイルの保存／読込
- 現在の表示範囲のPNG・閲覧用HTMLへの出力

## 基本操作

- **地図上をドラッグ**: マップを移動
- **マウスホイール**: 拡大・縮小
- **記号上をドラッグ**: 記号を移動
- **選択した記号のハンドルをドラッグ**: サイズ変更
- **防衛線の端点**: 長さ・向きを変更
- **防衛線の回転ハンドル**: 回転
- **地図上を右クリック**: その地点の経路点追加・座標コピー。関所では通行可否も切り替えられます

## スマホ操作

- 1本指ドラッグで地図を移動し、2本指ピンチで拡大・縮小できます。
- 地図を長押しすると、画面下から地点メニューが開きます。経路点への追加や座標コピーができ、関所では通行可否も切り替えられます。
- 配置済み記号を長押しすると、その記号の削除メニューが開きます。
- 配置済み記号をタップして選択すると、地図下部に「属性・複製・最前面・削除」の操作バーが表示されます。
- 経路点は地図上の番号マーカーを直接ドラッグして位置を変更できます。
- 左の「経路」を選択中は、地図上に「1点戻す」ボタンが表示されます。
- 設定画面は「作戦案・記号・経路・表示」の4タブに分かれています。
- 「編集／閲覧」でモードを切り替えられます。閲覧モードでは1本指操作が地図移動専用になり、記号や経路を誤って編集しません。
- 「全画面」で編集UIを隠し、マップだけを大きく表示できます。右上の「全画面終了」で元に戻ります。

## 経路探索

1. 左側の「経路」を選びます。
2. マップ上で開始地点と到着地点をクリックします。必要なら経由地点も追加できます。
3. 通行不可にしたい関所があれば右側で指定します。
4. 「経路計算」を押します。
5. 別経路も確認したい場合は「経路候補2」「経路候補3」をチェックします。

経路探索は陸路のみです。経路1は最短マス数を最優先し、同じ最短距離の中では駅路をより多く通る経路を優先します。候補2・3は、開始地点・経由地点・到着地点を除いて経路1と重ならない別経路を探索します。

## 作戦案A/B/C

A/B/Cは別々の作戦として管理されます。配置記号、経路、通行不可関所、表示する段階は作戦案ごとに保存され、切り替えると地図上の表示も切り替わります。

## 作戦記号の属性

配置済み記号を選択すると、その記号の下に属性が表示されます。名称、記号の大きさ、文字の大きさ、線の太さ、記号本体の表示／非表示、作戦段階を変更できます。

## 保存と共有

- **作戦保存**: 後から再編集できる作戦ファイルを保存します。
- **作戦読込**: 保存済みの作戦ファイルを開きます。
- **共有・出力**: 現在の表示範囲のPNG画像や閲覧用HTMLを作成します。共有用HTMLには、出力時の城・関所の表示設定、経路候補、作戦段階、記号の表示状態が反映されます。
