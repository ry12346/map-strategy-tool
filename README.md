# 真戦 戦略マップ

「信長の野望 真戦」PK1シーズン向けの非公式Web戦略ツールです。PK1マップ上で作戦記号の配置、城・関所検索、陸路の経路探索ができます。

## 基本操作

- 地図上をドラッグ：マップを移動
- マウスホイール／＋−：拡大・縮小
- 左の作戦記号を選んでクリック：記号を配置
- 配置済み記号をドラッグ：記号を移動
- 記号を選択して四隅をドラッグ：大きさを変更
- 防衛線の端点：長さを変更
- 防衛線の回転ハンドル：回転

## 作戦記号

自軍、敵軍、駐屯、幕舎、陣城、遷城、侵攻、防衛線、目標、メモを配置できます。配置後は名称・説明・色・透明度などを変更できます。

## 経路探索

1. 左の「経路」を選択します。
2. 開始地点、必要なら経由地点、到着地点を順番にクリックします。
3. 右側の「経路探索」で「経路計算」を押します。
4. 山・河川・海などの通行不可地点を避けた陸路を表示します。

関所を一時的に通行不可へ切り替え、別ルートを確認することもできます。

## 城・関所

- 城・関所名で検索し、その場所へ移動したり経路点へ追加できます。
- 城名・関所名、城マーカー・関所マーカーはそれぞれ表示／非表示を切り替えられます。

## ゲーム座標

画面下部にカーソル位置のゲーム座標を表示します。「コピー」を押すと `x,y` 形式でクリップボードへコピーできます。

## 保存・共有

- `.nssmap`：作戦を編集可能な状態で保存／読込
- PNG：全体または現在の表示範囲を画像として出力
- 共有用HTML：作戦内容を閲覧用HTMLとして出力

## 注意

本ツールは非公式のファンツールであり、ゲーム運営会社とは関係ありません。ゲーム側のマップや仕様が変更された場合、表示や経路判定が一致しなくなる場合があります。
