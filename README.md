# 真戦 戦略マップ

「信長の野望 真戦」PK1シーズン向けの非公式Web戦略ツールです。
APK/EBDLから復元した2000×3250のPK1論理マップを内蔵しており、スクリーンショットの結合や座標合わせをせずに使えます。

## 使い方

1. `index.html` をGitHub Pages等のWebサーバー上で開きます。
2. 起動するとPK1標準マップが自動で表示されます。
3. 経路探索をする場合は、左側の「経路」を選び、開始地点・経由地点・到着地点を順にクリックします。
4. 右側の「経路計算」を押すと、山・河川・海などの通行不可マスを避けた8方向の最短経路を表示します。
5. 関所を「通行不可」に設定すると、その関所を避ける迂回路を再計算できます。
6. 自軍・敵軍・駐屯・侵攻矢印・防衛線・メモ等の作戦記号は従来どおり配置できます。

城・関所は日本語名で検索できます。マップ上の日本語名称レイヤーは、提供された Noto Sans JP を使って生成しています。

## 主な機能

- PK1 2000×3250ゲーム座標の標準マップ
- 城119、関所38の検索・表示
- 山・河川・海等を考慮した8方向経路探索
- 陸路のみ / 航路を許可 の切替
- 関所ごとの通行可否指定
- 作戦記号の配置・編集
- 作戦段階ごとの表示切替
- `.nssmap` 保存・読込
- PNG出力・共有用HTML出力
- 任意の背景画像への切替（必要な場合のみ座標設定）

## 保存形式

### 作戦保存（`.nssmap`）

作戦記号、経路点、関所の遮断設定等を保存する編集用ファイルです。

### 共有用HTML

現在の背景と作戦内容を埋め込んだ閲覧用HTMLを出力します。

### PNG

全体または現在の表示範囲をPNGで出力できます。

## 日本語データ

`data/reference/` に、日本語化した城・関所・地域・地形のCSVを収録しています。UTF-8 BOM付きです。

## 注意

本ツールは非公式のファンツールであり、ゲーム運営会社とは関係ありません。ゲーム更新によりマップや通行条件が変更された場合は、内蔵データの更新が必要です。
