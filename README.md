# 真戦 PK2マップ

「信長の野望 真戦」PK2シーズン向けの非公式マップツールです。

スマホ利用を標準として、地図確認・城関所検索・経路探索・資源州確認に機能を絞っています。

## 主な機能

- PK2マップの閲覧、拡大縮小
- 城・関所検索
- 城名／関所名／資源州の表示切り替え
- 関所レベル表示
- 資源州エリアと境界関所の表示
- 陸路・海上航路を含む経路探索
- 城・関所だけでなく通行可能な任意地点を経路点に指定
- 通行不可関所を指定した迂回探索
- 別ルート候補の表示
- ゲーム座標表示・コピー

## スマホ操作

- 1本指ドラッグ：地図移動
- 2本指：拡大・縮小
- 通行可能地点をタップ：地点メニュー
- 経路点を長押しして上下へ移動：順番変更（変更後に自動再計算）
- 下から開くメニューの上部を下へスワイプ：閉じる
- 上部「城名」「関所名」「資源州」：表示切り替え

海上航路は常に経路探索の対象です。

## 注意

本ツールは非公式のファンツールであり、ゲーム運営会社とは関係ありません。


## v8

- 経由地は選択した順に後ろへ追加し、「ここから → 経由地1 → 経由地2 → ここまで」の順で指定できます。
- 地図追加中の「1点戻す」の横に「クリア」を追加しました。
- 「完了」を「詳細」に変更しました。
- 経路点が0件のとき黄色い件数バッジを表示しないよう修正しました。

- 経路点を1つ以上登録すると、画面下部に「通行可能な地点をタップ」操作バーを常時表示します。
- 右下の青い「経路」ボタンは廃止し、「詳細」から経路探索を開きます。


## v9

- 「1点戻す」後、2地点以上残っていれば経路を自動で再探索します。
- 「地図から追加」で地点を追加した場合も、2地点以上あれば経路を自動更新します。
- 到着地点が確定済みの状態で「地図から追加」した地点は、到着地点の直前へ経由地として追加します。
- 経路計算中に地点削除・クリアを行っても、古い探索結果が後から復活しないようにしました。
- 地点削除、並べ替え、関所遮断の変更を含め、経路条件を変更した操作では可能な限り自動再探索するよう統一しました。


## v10

- スマホの詳細画面で経路点の長押し並べ替えが動かない問題を修正しました。
- 並べ替えは各地点の「≡」を長押しし、そのまま上下へ動かします。
- 並べ替え中は詳細画面のスクロールに操作を奪われないようにし、上下端では自動スクロールします。
- 並べ替え完了後は経路を自動再探索します。
